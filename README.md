Field parameters allow users to dynamically change the measures or dimensions being analyzed within a report. This feature can help your report readers explore and customize the analysis of the report by selecting the different measures or dimensions they're interested in.

Bar chart with Field Parameters and Drillthrough : Drillthrough allows users to expand on a specific data point in a visual. To drillthrough aka see mpre detailed information, Right click on a specific bar and select Drillthrough. Users will be navigated to a target page with detailed information.
